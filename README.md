# Casa dintre Valuri – machetă demo

Site static (fără framework), publicat din `site/` pe Netlify.

- **Prețuri, sezoane, reguli, extra și zile ocupate:** `site/js/data.js` (toate sunt exemple).
- **Număr WhatsApp:** prima linie din `site/js/app.js` (`WHATSAPP_NUMBER`, exemplu `40700000000`).
- **Formular:** Netlify Forms (`name="rezervare"`), cu honeypot și câmpuri ascunse cu datele rezervării. Fără plăți, fără date de card.
- Pagina are `noindex,nofollow` și `robots.txt` cu `Disallow: /`.
